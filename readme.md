\# 네트워크 보안 기초

Windows 환경에서 본인 PC와 직접 만든 로컬 서버를 대상으로 진행한 네트워크 보안 기초 실습



\## 학습 내용

* \*\* IP 주소와 포트 \*\*: 통신 대상과 서비스 구분
* \*\* ipconfig, ping\*\* :  내 PC의 네트워크 정보와 응답 확인
* \*\*netstat , tasklist\*\*: 연결 상태, 포트, 실행 프로그램 확인
* \*\*Nmap\*\*: 로컬 서버의 포트 상태 점검
* \*\*JAVA 서버 실행 전후 비교\*\*: 서버 실행에 따른 포트 상태 변화 확인
* Wireshark\*\*: TCP 연결 과정과 패킷 관찰
* \*\*DNS\*\*:Python으로 도메인 이름의 IP 주소를 묻고 답하는 실습
* \*\*HTTP,HTTPS\*\*: 평문과 암호화 통신, TLS와 인증서 비교

\##사용 도구

JAVA, Python, Window cmd, Nmap, Npcap, Wireshark, Curl
