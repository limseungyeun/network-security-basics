netstat -ano|findstr :8081
▶  TCP    127.0.0.1:8081         0.0.0.0:0              LISTENING       PID표시(각자 다름)
netsta : 네트워크 연결 상태 표시
-a : 연결과 접속 대기 포트 표시
-n : 주소와 포트를 숫자로 표시
-o : 프로그램의 PID 표시
findstr : 8081 : 결과에서 : 8081가 들어간 줄만 표시
----------------------------------------------------------
nmap -sT -Pn -n -p 8081 127.0.0.1
▶ 실행중이면 8081/tcp open 표시
-sT는 TCP 연결 방식
-Pn은 호스트 발견 생략,
-n은 이름 조회 생략
-p 8081은 지정 포트만 검사
*open은 접속으 수락한 프로그램이 있다는 의미
